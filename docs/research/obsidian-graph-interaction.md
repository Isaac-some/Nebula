# 图谱疏密与交互对照

日期：2026-11-03。本页保留 0.3.0 对照记录；0.3.1 已取消默认选中并修正拖动时力场未启动的问题，见 [后续修复](drag-and-select-fix.md)。

## 参考依据

- [Obsidian 官方关系图谱说明](https://obsidian.md/help/plugins/graph)：节点与链接、悬浮突出关联、节点大小、文字渐隐、连线粗细，以及向心力、排斥力、连接拉力、连线长度。
- 本机 Obsidian 使用独立临时配置与 56 篇示例笔记，未改动用户原有知识库。实际展开“外观”“力度”，用鼠标验证悬浮高亮，操作滚轮观察缩放。截图：`obsidian-reference-controls.png`、`obsidian-reference-hover.png`、`obsidian-reference-zoom-out.png`。
- 保留 Atlas 的阅读方式：桌面单击显示摘要并固定焦点，双击打开全文；手机单击直接阅读。此项是产品选择，并非声称与 Obsidian 的单击打开全文完全相同。

## 改动及原因

1. 四项力度独立控制真实力导向布局。调整只重启布局计算，不自动把节点重新压回同一屏；“查看全图”由用户主动触发。
2. 直线连接合并同一对节点的多种关系，保留原始知识关系数据。平时淡显，悬浮突出当前节点相邻线，其余进一步淡化；移开后回到选中焦点。
3. 字号同时参考缩放、关联跳数和空间距离；重要标题先显示，远处与低优先级文字逐步淡出。以屏幕坐标进行标签避让，避免文字叠压。修复旧响应式 CSS 把所有文字强制设成同一字号的问题。
4. 点击保留鼠标下的节点位置，打开右侧摘要不触发全图重新居中，避免双击的第二次点击落空。拖动超过阈值才进入拖动，不触发阅读。
5. “疏密与显示”提供七项调节，包含文字密度、节点大小、线宽；浏览器保存偏好，支持恢复默认。
6. 支持空白处点击或 Escape 取消焦点，图谱键盘缩放和平移；焦点有可见指示，支持减少动态效果的系统偏好。
