# 0.3.1 拖动、高亮与下拉菜单修复

日期：2026-11-03。

## 复现与根因

Chrome 1512×982，连续两次把 AI Agent 拖到 RAG 的初始位置并短暂停留。

- 修复前：打开即选中 AI Agent，18 条关联线持续高亮；拖动后两节点中心距离约 0.55 px，RAG 位移小于 0.001 px，邻居与松手后的节点都没有运动。
- 重启力场的判断写在 `drag` 回调里，却要求 `event.active` 为 0。已安装 D3 的源码明确表明，该值在 `start` 时不包括当前手势，在 `drag` 时包括当前手势，因此实际拖动时始终至少为 1。条件始终不成立。
- 原有避碰和弹簧力仍在，但模拟器从未重启；之前的测试只检查被拖节点坐标改变，没有验证周边反应，未能发现问题。
- 页面初始化和重新读取知识库还会自动选中 AI Agent 或第一篇文档，造成默认持续高亮。

## 修复

- 跨过 5 px 拖动阈值后即时重启力场并提高活跃度；指针暂时固定拖动节点，周围节点实时避碰、关联节点通过弹簧跟随，松手解除固定并继续缓动。
- 拖动期间以正在拖动的节点为高亮焦点，屏蔽途经节点的悬浮，拖动不会误触发选择或打开正文。
- 初次加载和刷新不再自动选择文档；悬浮临时突出关联，主动点击后保留选择，空白处或 Escape 清除选择。悬浮另一个节点时不再同时画出旧选择的高亮环。
- 领域、知识类型、关系及学习状态统一为 Base UI 深色下拉组件；通过 Portal 展开，避免滚动面板的 overflow 裁切，菜单自动避开视口边缘。支持选中标记、悬浮、键盘、Escape 关闭并恢复焦点。

## 原始场景复验

同样操作的两次修复后实测：

| 指标 | 第一次 | 第二次 |
| --- | ---: | ---: |
| 默认选中 / 高亮线 | 0 / 0 | 0 / 0 |
| RAG 实时让位 | 24.6 px | 26.7 px |
| 两节点中心间距 | 24.9 px | 27.0 px |
| 关联节点跟随位移 | 5.9 px | 8.6 px |
| 松手后 250 ms 的运动 | 47.3 px | 53.2 px |
| 松手移开后的选中 / 高亮线 | 0 / 0 | 0 / 0 |

精确数字受实际帧率影响，测试断言交互行为而非这些特定数值。记录见 `drag-regression-after.json`，实测动图为 `drag-live-demo.gif`。

新增两组拖动/高亮回归和一组下拉菜单回归，先在旧版确认失败，再在修复后通过。全量还覆盖文字避让、缩放、文档读写、模糊/向量搜索、来源关系和移动端。下拉截图：`select-domain-fixed.png`、`select-status-fixed.png`、`select-mobile-fixed.png`。
