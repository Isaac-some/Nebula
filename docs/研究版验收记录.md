# 星知 Atlas 研究版验收

日期：2026-11-02；版本：0.2.1；运行地址：http://127.0.0.1:3210。

## 本轮结果

- 在原有 26 篇学习示例之外，实际导入 17 篇研究综述、8 篇概念笔记和 5 个机构入口，总计 56 篇、329 条有方向和类型的知识关系，无待补充目标。
- 综述覆盖 Anthropic、OpenAI、DeepSeek、Google、Google DeepMind。17 篇共综合 34 个独立一手来源，每篇 2—3 个，主要为 2015—2025 年的精选资料。来源清单见 `research/frontier-ai-sources-2026-11-02.md`。
- 研究与原理、应用、评测、前置知识和机构交叉连接。正文为原创中文归纳，区分研究观察、工程经验与适用边界。原始文献链接、机构和已核对日期在阅读页集中展示。
- 根据用户最新反馈，图谱改为 Obsidian 风格的平面力导向布局：圆点、直线连接，拖动节点时邻居随力布局调整；拖动画布平移，支持滚轮/双指缩放、重置与沉浸模式。已移除三维投影和旋转交互。类型和关系可分别筛选；同一节点对的多种关系合并绘线，悬停可见具体关系。
- 移除星图上方整块介绍区。统计放入星图标题栏；模糊检索直接搜索标题、别名、标签、摘要与机构，选择结果会解除筛选并定位。全库搜索仍保留本地向量与混合模式。
- 多来源与类型关系保存在 SQLite、Markdown 副本与 ZIP 导出中，Markdown 导入后可恢复。已有知识库导入会先备份并跳过同名文档，避免覆盖已有编辑。
